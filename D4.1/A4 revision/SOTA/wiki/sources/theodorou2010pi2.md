# A Generalized Path Integral Control Approach to Reinforcement Learning

*Theodorou, Evangelos; Buchli, Jonas; Schaal, Stefan* (2010). Journal of Machine Learning Research, vol. 11, pp. 3137-3181.

## TL;DR
PI^2: generalised path integral control for parameterised policies (DMPs); derives a probability-weighted policy-improvement rule with no gradients and only the temperature as open parameter.

## Method
Path-integral optimal control extended to parameterised policies; exponentiated cost-to-go weights per time step; applied to RL of motor skills.

## Evidence
Simulated and robotic learning tasks (robot dog, arm reaching).

## Relevance for Plan4ARI
Bridge from Kappen theory to robotics; the weighting rule is the same one later used by STOMP and MPPI.
