# B*: Efficient and Optimal Base Placement for Fixed-Base Manipulators

*Zhao, Zihang; Cui, Leiyao; Xie, Sirui; Zhang, Saiyao; Han, Zhi; Ruan, Lecheng; Zhu, Yixin* (2025). IEEE Robotics and Automation Letters, vol. 10, no. 10, pp. 10634-10641.

## TL;DR
B* solves base placement **jointly with the joint path** for an ordered sequence of end-effector poses as one continuous optimisation in configuration space, without precomputed reachability/IK databases. The fixed base is first relaxed into a per-timestep "mobile" base (3 extra planar DoF) so that a feasible start always exists; an ℓ1 penalty on the deviation from the mean base pose is increased over outer iterations until the base collapses to a single placement. Each subproblem is solved by trust-region sequential linear programming (SLP).

## Method
- **Formulation** (§III-A, Eq. 2–8): variables base q_b in SE(2) and joint configurations q_1..q_t; objective feasibility only (Eq. 3) or ℓ1 joint path length (Eq. 4, LP-friendly with slacks); equality: exact 6-D pose at every waypoint (Eq. 5); inequalities: base bounds, joint limits, signed distance ≥ 0 (self/ground collision; obstacles possible).
- **Outer layer** (Eq. 9–10): time-varying base q_b,i with penalty μ(j)·Σ‖q_b,i − mean‖₁, μ increasing; constraints turned into penalties to tolerate infeasible starts.
- **Inner layer** (Eq. 11): first-order linearisation in an adaptive trust region (sequential convex programming as in TrajOpt), LPs solved with COPT.
- **Initialisation** (§IV-A): IK with the 3 extra base DoF; random seed for the first point, previous solution for the next ones; up to 10 retries.

## Evidence
- Qualitative (§IV-B, Fig. 2): Franka Panda and KUKA iiwa, compound line + circle paths with 64 poses and ground collision.
- Quantitative (§IV-C): Franka, Kinova Gen3, KUKA iiwa, UR10; complexity levels l = 1..6 with t = 2^l poses (up to 64), 100 random sequences per robot and level → 2400 cases; baselines = cuRobo IK databases with 10/100/1000 solutions per pose + breadth-first search (b-10/100/1000). CPU only, Ryzen 9 5950X.
- Success rate 100% at all levels for B*, while baselines degrade sharply with length (b-1000 moderate up to level 2) (Fig. 3). Base-consistency error (ATE) about 5 orders of magnitude lower than the baselines, which stay at mm level (Fig. 4). Runtime lower than the baselines and log-linear in t (Fig. 5); sub-process times in Tab. I (outer layer from ≈ 79 ms at level 1 to ≈ 2.8 s mean at level 6, with large spread); retries grow from 1.1 to 2.0 on average (Tab. II).
- Real check (§V, Fig. 6): joint configurations for a line, a circle and both executed on a 7-DoF Kinova.

## Relevance for Plan4ARI
- Clean **continuous formulation of "one station for a whole path"**: base and path solved together, continuity built in (joint-distance objective over the waypoint chain). The relaxation trick (start mobile, then freeze the base) is attractive for stations: "AGV moving along the seam" → "AGV parked". With a linear 7th axis one could freeze only some of the base DoF.
- Seconds per 64-pose sequence on CPU: compatible with evaluating many (station, segment) pairs offline.

## Critical assessment (our view)
- **Exact 6-D poses**; no orientation cone, no free roll, no process tolerances (addable as constraints, but not shown). No time parametrisation, so the ±10% constant-speed requirement is not addressed.
- Local method: results depend on random initialisation; it returns one solution on one IK branch, gives no infeasibility certificate and no branch enumeration — a failed run does not prove that a station cannot cover a segment.
- The "five orders of magnitude" claim measures base-pose consistency across waypoints (the baselines discretise the base), not task quality; the baseline is sampling-limited by construction.
- Short synthetic sequences (≤ 64 poses) generated by small joint perturbations; real seams of metres at mm resolution are much longer. Only self/ground collision in experiments.

## Abstract (verbatim, arXiv)
> B* is a novel optimization framework that addresses a critical challenge in fixed-base manipulator robotics: optimal base placement. Current methods rely on pre-computed kinematics databases generated through sampling to search for solutions. However, they face an inherent trade-off between solution optimality and computational efficiency when determining sampling resolution. To address these limitations, B* unifies multiple objectives without database dependence. The framework employs a two-layer hierarchical approach. The outer layer systematically manages terminal constraints through progressive tightening, particularly for base mobility, enabling feasible initialization and broad solution exploration. The inner layer addresses non-convexities in each outer-layer subproblem through sequential local linearization, converting the original problem into tractable sequential linear programming (SLP). Testing across multiple robot platforms demonstrates B*'s effectiveness. The framework achieves solution optimality five orders of magnitude better than sampling-based approaches while maintaining perfect success rates and reduced computational overhead. Operating directly in configuration space, B* enables simultaneous path planning with customizable optimization criteria. B* serves as a crucial initialization tool that bridges the gap between theoretical motion planning and practical deployment, where feasible trajectory existence is fundamental.
