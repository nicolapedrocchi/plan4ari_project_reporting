# Model Predictive Path Integral Control: From Theory to Parallel Computation

*Williams, Grady; Aldrich, Andrew; Theodorou, Evangelos A.* (2017). Journal of Guidance, Control, and Dynamics, vol. 40, no. 2, pp. 344-357.

## TL;DR
Journal version of MPPI: derivation from path-integral control and parallel (GPU) computation, generalised importance sampling.

## Method
Path-integral derivation, importance sampling with arbitrary nominal control, CUDA implementation.

## Evidence
Simulated cart-pole, quadrotor navigation, race car.

## Relevance for Plan4ARI
Canonical reference for the algorithm and its parallel implementation.
