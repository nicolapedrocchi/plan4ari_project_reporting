Optimal TCP and Robot Base Placement for a Set of Complex Continuous Paths
Thomas Weingartshofer1, Christian Hartl-Nesic1 and Andreas Kugi1,2

Abstract— The robot base placement of an industrial robot in ﬂexible production lines is crucial due to the limited workspace of robots, in particular for complex continuous paths that change frequently. Costly and time-consuming repositioning of the robot can be avoided by merely adapting the tool center point (TCP) of the robot, which is the focus of this work. To this end, an algorithm for the optimal TCP placement for a set of tool paths is proposed. This algorithm is based on a fast joint-space path planner which is capable of moving through kinematic singularities and takes into account wide turning ranges of individual robot axes. Furthermore, the proposed concept also applies to the optimal robot base placement. The feasibility of the approach is demonstrated for a trim application in shoe production for a set of 44 complex continuous tool paths.
I. INTRODUCTION
While designing a production cell with an industrial robot, the position and orientation, i.e. the pose, of the robot base relative to the workpiece has to be chosen appropriately. In a ﬂexible robot work cell, however, products and robot tool paths may change frequently, possibly exceeding the capabilities of the work cell. Instead of adapting the complete setup or remounting the robot, which is a costly and timeconsuming process, it is often sufﬁcient to merely adapt the tool center point (TCP) of the robot using simple mechanical adapters. In this work, we focus on optimal placement of the TCP, which gained little attention in the literature so far.
Most works in the literature deal with base pose optimization only, considering different properties of the robot, i.e. kinematics [1], dynamics [2], manipulability [3], stiffness [4], and time-optimality [5]. For example, the stiffness and deformation of individual axes are considered for the base placement in milling tasks [6] to satisfy the high accuracy requirements. In some applications, i.e. mostly for milling and welding tasks, continuous end-effector paths are investigated. In [7] and [8], the elastostatic model of the robot is used to ﬁnd the optimal workpiece placement for continuous paths by minimizing the distance between the robot tool and its desired path. In [9], genetic algorithms are used that consider kinematic and dynamic manipulability and milling forces for a given trajectory. A fast search for a feasible workpiece pose is shown in [10] for a 7 degrees of freedom (DOF) robot with a tool axis redundancy, by successively considering additional constraints in an optimization problem. works concerned with robot base placement only consider individual poses instead of continuous paths, e.g., for spot welding [11], [12], short seam welding [13] or pick-andplace tasks using mobile robots [14]. Further works are focused on capability and reachability maps which are mostly used to position robots in grasping tasks, e.g., [15], [16] and [17].
For most applications, industrial robots with 6-DOF, a spherical wrist and axis ranges wider than 360° are used. Therefore, more than the usual 8 inverse kinematics solutions, which result in the same end-effector pose, have to be considered. In [18], the feasibility of the whole path is investigated while focusing mainly on cycle times. The work [19] combines two optimization loops, where in the inner loop, a redundant DOF is used to avoid singularities and the dynamical limits and in the outer loop, a particle swarm optimization searches for the global optimal robot base pose. Although wide axis ranges are considered in both works, the same solution of the inverse kinematics is used throughout a single path execution.
A survey of sampling-based path planning methods which systematically incorporate constraints is given in [20]. The graph-based Descartes algorithm described in [21] considers movements through multiple inverse kinematic solutions. However, this planner only outputs a single solution for each path planning problem and exhibits comparably long computation times. More advanced path planning algorithms like [22] and [23] cover a wider range of applications, but also suffer from higher computational costs. Hence, they could not be used for our purpose.
In this work, a fast joint-space path planner is proposed which considers all feasible kinematic solutions arising from wide turning ranges of robot axes. Additionally, this planner is capable to generate multiple joint-space paths besides moving through kinematic singularities. Based on the output of the joint-space path planner, the optimal TCP is determined as the solution of an optimization problem, in which the joint-space motions and robot limits are considered. To the best of the authors’ knowledge, such an approach has not been proposed in the literature yet. This work shows that adapting the TCP for a misplaced robot can avoid repositioning of the robot base. Furthermore, not only one path is considered, but a set of paths is taken as input for the optimization. The robot cell is only productive if the robot can execute all desired paths. The optimization problem is formulated in a general way, such that it is also applicable to optimal robot base placement.

VI. CONCLUSIONS In order to improve the ﬂexibility of robot work cells, an algorithm for the optimal TCP and robot base placement for a given set of complex task-space paths is proposed. To this end, a fast joint-space path planner is developed which calculates all feasible continuous joint-space paths. This planner takes into account all possible inverse kinematics solutions, including axes with wide turning ranges and moving through singular points. The optimization-based placement of the TCP and the robot base is performed using a surrogate optimization and systematically considers the distance to the respective joint limits. The proposed algorithm is applied in a trim application in shoe manufacturing to ﬁnd the optimal robot base placement and the optimal TCP placement in case of a suboptimally placed robot base. This work shows that in some cases it is sufﬁcient to adapt the TCP of the robot tool instead of redesigning the robot work cell. Additionally, placing the robot base optimally increases the reserves to the respective robot joint limits. Future work focuses on incorporating collision avoidance and the dynamic properties of the robot into the joint-space path planner for applications in constrained environments.
