Efficient Nonlinear Model Predictive Path Integral Control for Stochastic Systems considering Input Constraints
Hannes Homburger1, Stefan Wirtensohn1 and Johannes Reuter1

Abstract— This paper compares novel methods to efficiently include input constraints using the nonlinear Model Predictive Path Integral (MPPI) approach. The MPPI algorithm solves stochastic optimal control problems and is based on sampled trajectories. MPPI results from the physical path integral framework. Sample-based algorithms are characterized by the fact that they can be computed in parallel and offer the possibility to handle discontinuous dynamics and cost functions. However, using standard MPPI the input costs in the Lagrange term have to be chosen quadratic. This fact is unfavorable for various real applications. Further, in standard nonlinear model predictive control (NMPC) approaches hard box constraints on the control input trajectory can be treated directly. In this contribution, novel architectures based on integrator action are compared. The investigated input constraint MPPI controllers were tested on an autonomous self-balancing vehicle. Therefore both, simulation and real-world experiments are presented. This paper addresses the question of how the MPPI algorithm can be further developed to consider input box constraints. Videos of the self-balancing vehicle are available at: https://tinyurl.com/mvn8j7vf
I. INTRODUCTION
NMPC is an optimal feedback-control strategy based on repetitively online computing the optimal control input trajectory subject to the recent system state [1]. The first element of this optimal control sequence is applied to the system. Recently, a sample-based NMPC algorithm [2] was published, which is based on the physical framework of path integrals [3]. In this approach, the path integral over sampled trajectories is used to compute the optimal control input trajectory, providing an optimal solution concerning an input signal perturbed by additive white Gaussian noise (AWGN). Because in real controllers only a finite number of trajectories can be sampled, their information content is responsible for the optimizer’s, and thus the controller’s performance [4]. Recently, different methods, such as [5], [6], and [7] have been published to increase the information content of the drawn trajectories. However, using the standard MPPI algorithm, control input trajectory constraints are considered by either using an explicit quadratic cost [8] expression, implicitly by adding integrator action and a penalty term in the Lagrange cost function [9], or by clamping with Savitsky–Galoy filtering [2]. In this paper, novel methods are compared to consider input constraints using integrator action. In section II, the basics of the path integral control framework and the MPPI control algorithm are presented. In section III, the MPPI extensions to consider input constraints

II. PATH INTEGRAL CONTROL
For a special class of stochastic optimal control problems (OCPs), the corresponding nonlinear Hamilton-JacobiBellman (HJB) equation can be transformed into a linear second-order partial differential equation [3]. This enables the application of the Feynman-Kac lemma [10] which states that the value function solving the HJB is equal to a special forward diffusion process, that can be simulated by drawing samples of stochastic trajectories. Beside policy iteration-based optimal control approaches [11], [12], and [13] in the field of reinforcement learning (RL), recently, the framework of path integrals has been used to solve stochastic OCPs online in NMPC applications [2], [8], and [9]. In the following the basics of the MPPI algorithm according to [2] are described briefly.

B. Information-Theoretic Model Predictive Control
In the following the MPPI algorithm is described which is a stochastic NMPC algorithm based on the introduced path integral optimizer. Due to Bellman’s curse of dimensions and the representation problem, only in special cases, it is possible to represent and compute the optimal control law u∗k(xk) offline. However, due to the independence of the for-loop iterations in algorithm 1 lines 1-10, it can efficiently be computed in parallel tasks. Due to model-plant mismatch and unexpected disturbances the optimal control

input sequence is calculated repetitively in the NMPC framework. The only difference between the stochastic OCPs to be solved repetitively is the recent system state x0. Therefore, the controller’s performance can be significantly increased by shifting the control sequence and warm-starting. Those are well known methods to get a good proposal density q(V |Uˆ , Σ) [4]. Thus, the MPPI algorithm can be described as the following four steps, which are repeated cyclically:
1) Get recent system state x0 2) Optimize U ←PIO(U ) using algorithm 1 3) Apply the first element u0 4) Shift U by uk ← uk+1 , k = 0, 1, ..., N − 2
Recently, different full-scale applications have shown that this control approach is real-time capable and can handle nonlinear stochastic systems and discontinuous cost functions e.g. to drive aggressively with an autonomous model car [2] or to autodock a vessel [9]. In most standard NMPC approaches, input constraints can be considered directly within the transcription and added to the resulting nonlinear problem as inequality constraints on the decision variables. However, using the standard MPPI algorithm according to [2], it is only permitted to penalize high control input values with quadratic input costs used in (4). In the next section, we present and compare different approaches to consider input constraints in the MPPI scheme.

The validity of the path integral framework is based on quadratic input costs (4) and no restrictions on the feasible control set. Thus, we can use the idea of applying integrator action with the extension of the state space
xk = xk , wk
where wk ∈ Rnu are the states of the integrator at time instance k, thus the extended dynamics is given by
xk+1 = F (xk, vk) = F (xk, wk) I (w , k, vk)
where I denotes a discrete time integrator of the dimension nu. Thus, the control input vector of the real system has become part of the state vector of an expanded system. Regarding the expanded system dynamics, the following two

properties of the path integral framework described in [2] can be exploited to solve (7):
1) The state costs l in (4) can be chosen arbitrarily, thus the input box constraints can be considered by adding a nonlinear penalty term.
2) The dynamics F defined in (1) can be discontinuous, thus we can saturate the integrator state wk due to its artificial nature.
These two methods will be explained in the following.

A. Input Constrained MPPI Control using Penalty Terms
Similar to merit functions, known for globalization in standard NMPC approaches we can define the state-dependent costs as

u l(xk) = l(xk) + σ ( −≤uˆ≤u min + ||wk − uˆ ||1), (8)
where σ ∈ R+ denotes the penalty coefficient. Note, if and only if u− ≤ wk ≤ u+ holds, the box constraints are satisfied and the penalty term vanishes. For implementation due to the convexity of the minimization, an element-wise comparison causes only low computational effort. This approach is called penalty term (PT) in the rest of the paper.

B. Full-Scale Results
To test the performance of the MPPI controller in the full-scale experiment, the MPPI controller is applied on the self-balancing test vehicle MonoChair2 shown in Fig. 1. For this purpose, the MPPI controller is implemented on the NVIDIA® Jetson Nano™ Developer Kit and connected to the system with Ethernet. Then, the same experiments as in the previous section are conducted, although only M = 2000 can be drawn due to the computational effort. While Fig. 5 shows the generalized pose during the experiments, the corresponding desired velocity sequences are shown in Fig. 4. The SI approach in full-scale shows similar behavior as in simulation in both, the evolution of the generalized pose and the sequence of desired velocities. Due to the plant-model mismatch, the PT approach brakes at t = 11.5 s. This further deteriorates the behavior. An appropriate criterion to compare the performances quantitatively is the accumulated Lagrange cost (12) over 30 s. This yields JPT,sim = 478, JSI,sim = 418.7 JPT,full = 522.8 and JSI,full = 425.3, showing that SI is the recommended approach because it performs better in both scenarios.
