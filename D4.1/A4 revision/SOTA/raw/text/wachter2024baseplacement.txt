Optimization procedures, in which the full robot motions are considered, are much more demanding since the robot trajectories must be updated for each base placement. For example, Weingartshofer et al. (2021) embed a full trajectory planner for a given set of complex continuous paths. Similarly, Kamrani et al. (2009) investigated the relationship between cycle time variations and base placement for given paths with the major limitation of not considering collisions.
Free-space robot motions pose additional challenges to trajectory planning due to the much larger search space. The work of Baizid et al. (2015) solves the shortest distance traveled by the manipulator for a spot-welding application. Spensieri et al. (2016) utilized a reachability index map and evaluated the actual cycle time only for specific local minimums of the map. This two-stage optimization scheme only provides a list of base placement candidates instead of utilizing the cycle time within the optimization. In the work of Valsamos et al. (2022), joint velocities during task execution under a given end-effector velocity are minimized, considering only the shortest paths indicated by direct motions between two frames, not considering collisions.
This work proposes a robot base placement optimization, considering the complete process scenario with free-space robot motions in an environment with obstacles. To this end, a P2P trajectory planner is embedded in a highly parallelized optimization. The optimization aims to minimize cycle time and can incorporate other heuristics for placement, like time-energy or throughput-adaptivity.
3. PROBLEM DESCRIPTION
This work aims to determine the optimal robot base placement b = {x, y, z, r} for a multi-P2P assembly task, with the robot position [x y z]T and the rotation r around the z-axis w.r.t. the world frame. The assembly task is specified by a sequence of N task-space poses X = {xi | i = 1, . . . , N }, which are traversed using consecutive free-space P2P movements. The N − 1 trajectories for the P2P movements between the sequence X are planned in the joint space, where q(t), q˙ (t), and q¨(t) are the position, velocity, and acceleration of the robot, respectively. For each pose xi, i = 1, . . . , N , a set of inverse kinematics (IK) solutions Qi = {qij | j = 1, . . . , Mi} is obtained, where Mi is the number of IK solutions for the pose xi.
The robot movements are subject to constraints such as collisions with the environment, robot dynamic constraints, and the cyclic task constraint x1 = xN . The latter implies that the corresponding IK solutions q1 and qN must match to form a cyclic robot motion.
The three distinct optimization goals (a) cycle-timeoptimal, (b) time-energy-optimal, and (c) throughputadaptive are investigated, which are further detailed in Sections 4.4–4.6.

4. ROBOT BASE PLACEMENT OPTIMIZATION
In this section, the proposed optimization procedure is described in detail. It consists of a Bayesian optimizer, which asynchronously orchestrates W workers running in parallel, see Fig. 1. Using an embedded cyclic P2P trajectory planner, each worker solves the assembly task for a given robot base placement and evaluates the cost. This way, the Bayesian optimizer evaluates the placements of interest and updates the underlying surrogate model of the cost function. The P2P trajectory planner is introduced in the following subsections, and subsequently, the optimization procedures for the three goals from Section 3 are explained.
4.1 Point-to-Point Planner
For practically time-optimal trajectory planning in clustered environments, the via-point stochastic optimization (VP-STO) planner is utilized (Jankowski et al., 2023). This task-agnostic planner utilizes a low-dimensional timecontinuous trajectory representation in the joint space based on via points, which by design adheres to the kinodynamic limits of the robot. Additionally, the planner optimizes the via points stochastically using an evolutionary strategy to minimize the movement duration and other task-related cost terms.
The algorithm of the original work (Jankowski et al., 2023) was tailored to the application as the innermost planner of the robot base placement optimization. In order to reduce the likelihood of converging to local minima, the initial explorations are performed using a 100× larger population size, giving the algorithm a broad exploration and a higher chance to find the true optimum. After the first ten evolutionary steps, the population size is decreased to only proceed with the ten best participants. These modifications decrease the algorithm run time and improve the convergence speed. Lastly, a warm start is implemented using previous solutions for similar robot base placements. The collision check of the individual trajectories is performed with Mujoco Mjx, a multi-purpose physics engine (Todorov et al., 2012).

4.3 Optimal Robot Base Placement
The robot base placement optimization uses the blackbox optimization (BBO) routine of Li et al. (2021) to asynchronously select placements of interest and evaluate them in parallel using the workers, see Fig. 1. For each selected placement, a worker executes the cyclic P2P planner from the previous section to compute and evaluate the actual robot trajectories. The evaluated costs are used to update the surrogate model of the cost function for a specified number of iterations and find the global minimum cost.

4.4 Cycle-Time-Optimal Robot Base Placement
The cycle-time-optimal robot base placement aims to minimize the total cycle time of the assembly task X . To this end, only the trajectory duration T is chosen as cost C in Algorithms 1 and 2. The P2P planner outputs the minimal transition time between two robot configurations considering collisions and kinodynamic limits. Consequently, the optimization leads to a robot base placement where the actual trajectory duration is minimized instead of a performance metric, as in Makhal and Goins (2018) or Bachmann et al. (2021).

4.6 Throughput-Adaptive Robot Base Placement
Flexible automation requires the robotic work cell to handle high-throughput scenarios with time-optimal robot motions and low-throughput situations with energy-saving trajectories. However, these two requirements contradict each other when optimizing the robot base placement. In the following, the optimization goal throughput-adaptive is introduced, which provides a robot base placement, considering these dynamic changes in the throughput.

The expected maximum cycle time Tmax for low-throughput situations is specified beforehand for the optimization. The innermost P2P trajectory planner in Algorithm 1 uses the trajectory duration T as cost C, leading to a timeoptimal trajectory planning. 5. SIMULATION RESULTS

This section investigates the robot base placement optimization for a robotic work cell with two distinct scenarios, see Fig. 3. The assembly task uses a Selective Compliance Assembly Robot Arm (SCARA). It consists of a sequence of N = 14 poses in the set X to pick and place objects between seven workstations. The scene is mostly free of obstacles in the sparse scenario (without the red fence in Fig. 3). In contrast, considering collisions is essential to successfully plan trajectories in the complex scenario (including the red fence).
Given the joint limits of the robot, where the last joint spans the range of [−2π, 2π], up to M = Mi = 6 IK solutions exist for each pose in X , i = 1, . . . , N , yielding a graph with M × N nodes and M × M × (N − 1) trajectories. By exploiting rotational symmetries in the last axis, not all trajectories need to be computed, reducing

5.1 Sparse Scenario
To give a qualitative overview of the 3-dimensional search space for the robot base placement in the sparse scenario (position x and y and rotation r), a full grid search is performed and visualized for the cycle time (Fig. 4a), and the time-energy cost (Fig. 4b). The color coding indicates the normalized value and infeasible points are omitted. The red and blue dots indicate the minimum cycle time and the time-energy cost, respectively.
Next, the optimization procedure from Section 4 is applied to the sparse scenario. The black dots in Fig. 4a represent the evaluated points in the search space projected into the xy-plane. The initial random samples cover the search space, and the BBO quickly converges to regions close to the global optimum (red dot). Compared to the cycletime-optimal robot base placement, the worst feasible placement has a 1.78× higher cycle time. Conversely, this translates to a reduction of 44 %. The placement chosen by the human expert is 1.21× slower, see Section 5. In the sparse scenario, the time-energy-optimal as well as the throughput-adaptive robot base placements are very similar (blue dot in Fig. 4a). Additionally, these placements also coincide with a local minimum of the cycle time. The worst placement therefore has a 2.11× higher energy consumption, corresponding to a percentage gain from worst to best of 53 %.

5.2 Complex Scenario
The results for the complex scenario in Section 5 show that the cycle time can be reduced by 17 % (1.21×) and the time-energy cost by 23 % (1.30×) compared to the worst robot base placement. The difference between the worst and the best placement is less pronounced in this scenario than in the sparse scenario. This behavior originates from the robot’s occupied workspace due to the red fence, which significantly reduces the search space, see Fig. 3.
The throughput-adaptive placement shows an overall good performance. It is close to time-optimal in the highthroughput situation (4 % higher compared to cycle-timeoptimal placement) and is most energy-saving in the lowthroughput situation (14 % lower compared to cycle-timeoptimal placement), which is achieved by applying the optimization-based trajectory scaling (4) for a given Tmax.

5.3 Comparison to the State of the Art
This section compares the proposed optimization procedure to state-of-the-art schemes for robot base placement, specifically the Manipulability (Moriguchi et al., 2022; Yoshikawa, 1985), the Cartesian-distance (Bachmann et al., 2021), and the Joint-space-distance formulation of Baizid et al. (2015). The latter uses the cost

to transition from a robot configuration q1 to q2 with m degrees of freedom at maximum joint velocity q˙j,max. This results in minimum-distance movements in the joint space without considering collisions.
The results in Section 5 for the sparse scenario show that the placement using the manipulability performs 17 % worse than the cycle-time-optimal placement. Additionally, not considering collisions during placement optimization leads to an 11 % higher cycle time during operation.

The approach Cartesian-distance converges to an invalid placement for both scenarios. In the complex scenario, the state-of-the-art placement schemes do not provide valid solutions with which the assembly task is executable; see the red crosses in Section 5. This highlights the necessity of full trajectory planning within the optimization procedure for environments with significant obstacles.
5.4 Algorithm Runtime
The proposed method’s algorithm runtime for obtaining an optimal robot base placement in the considered scenes is approximately 80 min on a computer with 90 cores. Note that this runtime strongly depends on the underlying parameters of the P2P planner, the complexity of the environment, and the sequence length of the assembly task. In contrast, the runtime of placement methods based on performance indices is only in the order of a few minutes on the same hardware. However, the results in Section 5 show that these methods yield sub-optimal robot base placements in cycle time and energy, or they fail to provide valid placements in the presence of significant obstacles. The proposed method provides a global optimum and valid robot trajectories, which can be scaled easily to a given cycle time Tmax.
6. CONCLUSIONS
This work proposes a procedure to optimize the robot base placement of a robotic work cell for cycle-timeoptimality, time-energy-optimality, or adaptivity to dynamically changing throughput. A Bayesian optimizer is combined with a cyclic P2P trajectory planner to explore the search space rapidly in a highly parallelized manner. The P2P planner considers the complete scenario, including kinodynamic robot limits, collisions, and all robot configurations. Planning the actual trajectories yields significant performance improvements even in environments with many obstacles, where state-of-the-art methods fail to provide valid robot base placements. The throughput-adaptive placement performs close to cycletime-optimality in high-throughput situations and significantly reduces energy consumption in low-throughput situations. This adaptivity results from scaling the robot trajectory to a given cycle time. This work shows that significantly reduced cycle time and energy consumption can be achieved by carefully choosing the robot base placement within the work cell.
Future work aims to expand the application of this method to optimize various other components of robotic cells. By incorporating additional optimization parameters, the end-of-arm tool, the kinematic structure of robotic manipulators, individual task positions or the full cell layout could be optimized.
